# UIUX Atlas

Biblioteca interactiva de patrones UI/UX y generador de prompts para herramientas de desarrollo con IA.

> Proyecto en construcción. La primera versión incluye catálogo visual, buscador, filtros, favoritos locales y generador de instrucciones.

Stack previsto: React, TypeScript, Vite y Tailwind CSS. Sin backend ni credenciales.
